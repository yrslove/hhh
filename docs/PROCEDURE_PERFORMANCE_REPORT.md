# Анализ времени внесения процедур

## Текущий путь для одного пациента

1. При обычном запуске Excel читается **один раз**. Загрузчик выбирает только лист расписания ЕТФТ и лист распределения. Из них формируются план процедур, даты, время, специалист, код услуги и данные пациента. Книга закрывается до работы с Doctor Eleks.
2. При продолжении после контрольной точки готовый план берётся из SQLite. Excel повторно не открывается.
3. Для каждой процедуры выполняется работа в Doctor Eleks. После подтверждённого ответа сервера прогресс записывается в SQLite. Если предыдущая попытка была прервана, перед повтором проверяется, нет ли уже созданной процедуры в Doctor Eleks.
4. После пакета список Doctor Eleks однократно проверяется на отсутствие пропусков и дублей. Excel для этой проверки не нужен.

В сценарии внесения процедур Excel используется только для чтения. Отметки жирным шрифтом, резервные копии и сохранение XLSX удалены. Между процедурами файл не открывается и не проверяется. Клики и ожидания сайта не менялись.

## Замеры

Сравнение на рабочей книге размером около 2,6 МБ без обращения к Doctor Eleks:

| Операция | Полная загрузка | Выборочная загрузка |
| --- | ---: | ---: |
| Загрузка книги | 10,78 с | 4,39 с |
| Разбор ЕТФТ | 1,09 с | 1,00 с |
| Сохранение XLSX после процедур | 16,94 с за одно сохранение | 0 с, сохранения нет |

Для двух способов чтения совпали все 6 987 записей расписания, технические предупреждения и данные выбранного пациента. Ранее после каждой из 14 процедур выполнялось полное сохранение, что давало примерно 14 × 17 = 238 секунд только на запись XLSX. Сейчас этот расход отсутствует. Время полного прохода с Doctor Eleks не замерялось.

Отдельный вызов построения плана для пациента на этой книге занял 4,53 с. Он использует те же два листа и закрывает Excel до начала действий на сайте.

Выборочная загрузка использует внутренний API установленной версии `openpyxl`. Если он станет несовместимым после обновления библиотеки, программа перейдёт на обычное полное чтение и запишет предупреждение в журнал; Excel всё равно не будет изменён.

## Состояние после сбоя

Список подтверждённых процедур и ячейка незавершённой попытки хранятся в SQLite. После перезапуска план доступен даже без исходного Excel-файла; потенциальный дубль проверяется в Doctor Eleks. Источником истины о создании процедуры служит ответ сервера и итоговая проверка списка, а не форматирование Excel.

Проверены 73 автоматических теста. Дополнительно результат выборочного чтения сравнивался с полной загрузкой рабочей книги. Полный прогон с реальным Doctor Eleks не выполнялся.

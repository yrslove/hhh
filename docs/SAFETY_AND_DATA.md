# Дані та контрольні точки

## Не зберігати

- пароль КЕП;
- OTP;
- секретні ключі у Git;
- повні консультативні висновки в audit.jsonl.

Текст висновку зберігається локально в SQLite тільки для наступного діагностичного кроку.

## КЕП

Фінальний юридично значимий підпис залишається ручною контрольною точкою.

## Діагнози

Функція `diagnosis_prepare` структурує інформацію і приймає вже підтверджені коди.

Програма не повинна автоматично додавати медично непідтверджені діагнози заради оплати.

## Backups

Перед записом у робочий Excel створюється копія у `data/backups/`.
